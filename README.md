# Super Mario Tic-Tac-Toe

Uma recriação do clássico Jogo da Velha com temática retrô do Super Mario, desenvolvida em **Angular**. O projeto traz uma interface estilizada inspirada em telas de consoles 8-bits e calculadoras clássicas, permitindo disputas entre o **Cogumelo (🍄)** e a **Estrela (⭐)** com contagem de placar em tempo real.

---

## O que é o projeto?

O **Super Mario Tic-Tac-Toe** transforma o tradicional jogo da velha em uma experiência nostálgica e interativa. Com um visual cuidadosamente trabalhado para ocupar a tela inteira sem barras de rolagem, o jogo inclui:

- **Modo Versus Local:** Turnos alternados entre dois jogadores.
- **Placar Interativo:** Contador de vitórias dinâmico para cada personagem.
- **Verificação Automática:** Validação instantânea de sequências vitoriosas (linhas, colunas e diagonais) e empates.
- **Estética Retrô:** Layout limpo com tipografia estilo pixel art e paleta de cores clássica do universo Mario.
